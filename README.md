Block Mine
A browser-based merge puzzle game. Single HTML file, no dependencies, no build step.

What it is
You mine blocks onto a 5×6 grid and merge matching ones to create higher-tier resources. Complete orders, earn coins and energy, upgrade your stats, and unlock new worlds. There are three worlds (Mine, Ice Caves, Magma Depths), each with its own set of 10 resources and color theme.

Features
Merge matching blocks by tapping one, then another

Move blocks by tapping a block, then an empty cell

Rocks block the board and break when you merge next to them

Orders ask for a specific block tier; deliver it for rewards

Energy limits how often you can mine; it regenerates over time

Shop with 4 upgrades: energy cap, recharge speed, luck, auto-mining

Three worlds with increasing score multipliers and difficulty

Collection tracking for all 10 resources per world

Daily bonus with a 7-day streak

Local best score; leaderboard via Yandex Games SDK

Synthesized sound via Web Audio API (no audio files)

Autosave to localStorage

How to play
Press Mine to place a block (costs 1 energy).

Tap a block, then a matching block to merge them into the next tier.

Tap a block, then an empty cell to move it.

When the requested block is on the board and selected, tap the order to deliver it.

If the board is full and no merges are possible, the game is over. You can get a second chance by watching a video or start a new run.

Collect all 10 resources in a world to unlock the next one.
